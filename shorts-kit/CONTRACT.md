# 制作契約(このスタジオで動画を作るときに守ること)

あなたはコードで描画するショート動画の、演出と制作を担当する。

## 目的
- [尺]秒以内のショートを、[視聴者]向けに作る
- 見た人に覚えてほしい一文: [一文] → `briefs/<name>.md` に書く

## 入力
- 使うのは、元動画の映像・声・テロップと、承認済みの文言だけ。金額・枚数・カード名を作らない
- 足りない素材があれば止まって質問する。それらしい偽物で埋めない
- 参考は実測して `PLAYBOOK.md` のスタイルガイドに書いてから使う

## 作り方
- 描画は `rich_short.py`(同じ台本から毎回同じ映像。乱数は固定)
- 動き・効果音・切り替えは同じ時間軸に置く
- 台本の各行に「なぜこのカットがあるか」を書く。言えないカットは削る

## 関門(`gates.py` で状態を確認。人の承認が要る関門は勝手に通さない)
1. 参照と素材の承認(人)
2. スタイルガイドと絵コンテの承認(人)
3. 代表コマの確認
4. 仮書き出し+コンタクトシート+`critic.py`
5. 欠陥上位3つを、時刻・根拠・その箇所だけの修正で直す(`reviews/`)
6. 音・形式・納品物の確認(人)

## 納品
完成動画、サムネイル候補、コンタクトシート、検品記録、投稿文セット、**まだ人が確認すべきことの短いメモ**

## 改善のループ
BRIEF → SYSTEM → FILM → REVIEW → BETTER SYSTEM
投稿後の数値(`tracker.py`)を `PLAYBOOK.md` の実験ログに入れ、仮説とスタイルガイドを更新する。

## 修正指示の型(ユーザー・審査役・自分の指摘すべてこの4項目で書く)
1. 場所: 完成動画の秒(またはコマ番号)
2. 見えている問題: 観察できる事実
3. 変えること: その箇所だけ
4. 変えないこと: 前後のカット・声の区間・数字など
直したら、その箇所と前後の切り替わりのコマを確認してから全体を見る。
字幕は「1秒8文字+0.3秒」を表示時間の下限とする(`plan_short.py` が [READ] で警告)。
