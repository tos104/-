## 2. 転用の考え方

型は「ジャンル」ではなく「視聴者の感情の動き」で捉える。遊戯王の型をポケカ・ドラゴンボールに移すときは、次の 3 つを入れ替えるだけにする。

- **対象**: 青眼 → リザードン / 悟空
- **価値の軸**: 値段・希少性・見分け方・後悔
- **形式**: N選 / 鑑定結果は？ / 1年前と今

例: 「1 年前は 100 万以下 → 今 240 万」(価値の時間差) は、どの TCG の高騰カードにも同じ形で使える。

## 3. 枠の外のアイデア(未検証・試す価値順)

1. **鑑定結果の予想を視聴者にさせる**: 「PSA 何点だと思う？」で止めてコメントを集め、結果は次のショートで出す(続きを見る理由 = 登録の理由)。
2. **長尺 1 本 → ショート 5 本の分解を前提に撮る**: 撮影前に「5 つの一言」を決めてから撮る。切り抜きではなく、素材集めとして撮影する。
3. **値段の時間差シリーズ**: 過去動画の映像 + 現在の相場で「あの時買ったカードは今いくら？」。既存の素材を使い回せる。
4. **失敗・損の回**: PSA9 / ケース割れ / 買い時を間違えた系は、参考 2 チャンネルとも伸びている(タイヘイ「【悲報】購入タイミングを間違えました」22 万)。
5. **コメントへの返信ショート**: 実在するコメント(例:「ケースのスタンド名は？」「海外代行はどこ？」)に答える。質問をした本人が拡散してくれる。

## 4.7 競合のショート 26チャンネル・4,799本(2026-10-25・タイトルと再生数)

方法: `competitor_patterns.py`(データ `research/competitors_2026-10-25.json`、結果 `research/competitor_patterns_2026-10-25.txt`)。
各チャンネルの中で「再生 ÷ 中央値」に直して比べる(規模の差を消す)。**再現** = 8ch 以上で比較でき、倍率の中央値 ≥1.2(≤0.83)、同じ向きのチャンネル ≥65%。
限界: タイトルしか見ていない(サムネ画像はこの環境から取れない)/古い動画ほど再生が積み上がる/相関であり因果ではない。

### 再現したパターン(事実)
| # | 型(抽象) | 根拠 | tt での具体化 |
|---|---|---|---|
| R1 | **判定が下る瞬間**(他人の評価で価値が確定する) | 鑑定の返却・結果 8ch ×1.38(75%)/PSA の語 8ch ×1.29 | 1本=1枚の判定。タイトルに PSA/ARS と点数の争点を入れる(例「PSA10か9か、4,000円のバンギラス」) |
| R2 | **価値を数字で見せる** | 金額あり 16ch ×1.20(81%) | タイトルに金額を**1つ**。最初の1コマにも金額 |
| R3 | **小さな元手**(自分でもできそうな入口) | 1万円未満の金額 9ch ×1.22(67%)/安く買った 7ch ×1.56(71%・候補) | 「4,000円で買った」「2,500円の」から始める。#4 シズク 4,000→25,000 が該当 |

### 候補(チャンネル数が足りない・向きが割れる。tt で試して確かめる)
- 意外な結果(まさか・！？) 17ch ×1.21 だが上がったのは 59% → 当たり外れが大きい
- 賭け型(オリパ・くじ・開封) 20ch ×1.18・55% → ハマると桁違い(tt 自身の最大ヒットも一番くじ 神引き ×28.6)

- 金額を2つ並べる(A→B) 5ch ×0.48・**5ch すべてで下がった** → 数が少ないが要注意。金額は1つに絞る

### 効かない・逆効果寄り

## 4.98 伸びたテーマを深掘りする(2026-11-01・全事業に共通)

出典: ユーザー共有の記事スクショ(筆者・媒体は不明)。記事が挙げた改善は3つ: ①伸びたテーマを深掘りする ②投稿を1日2本→3本 ③完成動画を見直してテロップと話の流れを直す。記事自身も「どれが効いたかは断定できない」と書いている。

### 検証(事実。競合 26ch・4,799本のタイトルと再生数)
方法: `theme_followup.py`(結果 `research/theme_followup_2026-11-01.txt`)。各チャンネルで、中央値の2倍以上だったショートの後の10本のうち、同じテーマ語(そのチャンネルで2回以上・10%以下しか出ない語)を持つものを「深掘り」として比べた。
- 深掘りは、同じ期間のほかの動画の **×1.29**(中央値)。上がったのは **18/23ch(78%)**
- 対照: 普通の動画の後に同じテーマを続けたもの → 倍率 0.99(効果なし)。当たり後の深掘り 1.60 と比べ、**20/20ch で当たり後が上**
- 窓5本・20本、当たり3倍でも同じ向き(×1.16〜1.27、67〜78%)
- **tt 自身は34本中、当たり後の深掘りが1回しかない** → まだ使っていない伸びしろ
- 限界: 相関。テーマ自体の流行に乗っているだけの可能性がある(それでも「流行中に重ねる」は打ち手として同じ)/テーマはタイトルの語でしか見ていない

### 追加検証(2026-11-01・`research/shorts_*_2026-11-01.json`)
- **nori(FX テクニカル・131本・中央値3,677)**: 当たり後の深掘りは4本しかなく、×1.18 vs その他 ×1.25 で差は見えない(数が少なく判定不能)。
  一方、**掘りすぎの兆候**: 「三尊」57本は ×0.74(含まない ×1.14)、「逆三尊」32本 ×0.68、「ネックライン」10本 ×0.80。当たり上位6本中3本が三尊なのに、全体では下回る → 当たったテーマを繰り返しすぎて薄まった可能性(推測・新旧の差を除いていない)。少ない「サポ(レジサポ転換)」4本は ×1.51 → まだ掘っていない候補
- **tt(42本・中央値2,046)**: 当たり後の深掘りは2本(×0.98)。当たりのほとんどが一番くじ・供給不足BOX など **話題の瞬間もの**(×28.4・×20.0・×9.8)で、続けて深掘りした記録がない

### 注意(実験ログから)
- **深掘りするのは「テーマ」で、「型」ではない**。#6 究極竜(4,000円+ARS結果は？)が当たった翌日、同じ型の #4 シズクは2日目 +29 で止まった。型の使い回しは深掘りではない

- ②の本数増は 4.95-4「本数は増やさない」と矛盾する。本数は変えず、**枠の中身を深掘りに回す**

## 4.995 「買うまでの道」を作る(2026-11-01 ユーザー共有・まな｜AIの申し子「猿でもわかる『稼ぐ特化』のSNSマーケティング大全」X記事 2026-08-07・閲覧31万)

### 要点(記事の主張)
1. **売上 = 見込み客の数 × 教育された割合 × 成約率 × 単価**。再生・いいね・フォロワーは「途中の数字」
2. **バズと集客は別**。「再生1万で見込み客0」より「再生1,000で相談3件」。毎回「この投稿で集まるのは誰か、将来の客か」を問う
3. 集客の入口は3つ: **痛み / 欲しい未来 / 思い込みを壊す**(4.31 の4分類と重なる。逆張りは理由が続く場合だけ)
4. 役割分担: 短尺 = 入口、長尺 = 納得、プロフィール・固定 = 案内所、DM = 診察室、商品 = 実行の支援
5. 投稿は5種類: **集客 / 教育(判断基準を変える) / 証拠(事例・前後・検証、条件も出す) / 人柄・思想 / 販売**。販売ゼロは「商品があることに気づかれない」
6. 数字は「投稿の閲覧 → プロフィール → フォロー → 無料資料・DM → 相談 → 購入」の **どこで詰まっているか** を見る診断。再生だけで良し悪しを決めない
7. 失敗10個のうち関係が深いもの: テーマが広すぎる / 見込み客でない人を集める / 投稿内で完結させすぎる / 商品の話をしない / 数字を見ずに感覚で直す

### 記事の数値(そのまま使える)
- **イージング**: 入りは ease-out、出は ease-in で **入りより40〜50%短く**(例 400ms/200ms)、画面を横切る動きは ease-in-out。linear は回転・進捗バー・ループの位相だけ
- **ばね**: 減衰比 1.0=弾まない / 0.7〜0.85=上質 / 0.4〜0.6=遊び / 0.3未満=漫画。**位置と大きさは弾んでよい、透明度と色は弾ませない**
- **長さ**: UI の反応 100〜200ms / UI の動き 200〜500ms / 主役の登場 600〜900ms / 文字は1コマずつ・単語は60〜120ms・リストは40〜80ms ずらす。前の要素が30〜50%進んだら次を始める
- **主役は1カットに1つ**。脇役は主役の50〜70%の距離・100〜200ms 遅れ。背景の動きは5%未満
- **拍**: 1拍のコマ数 = fps×60÷BPM。**毎回時刻から計算して丸める**(丸めた値を足し続けると32拍で2コマずれる)。**カットは拍、レイアウト替えは4拍ごと**(毎拍すべて変えると疲れる)
- **文字の表示時間**: 1語あたり0.3秒+0.5秒(2語なら1.1秒)。表示中は2%のゆっくりした寄りで止まって見せない
- **カメラ**: ease-in-out-quart など一番柔らかい曲線。視差は 前1.0・中0.5・奥0.2
- **安全**: 文字のコントラスト 4.5:1 以上を全コマで / **点滅は1秒に3回まで**(WCAG)
- **音**: 無音で成立させてから音。−14 LUFS・ピーク −1 dBTP。**音は絵の1コマ後**(先に鳴ると違和感が強い)
- **禁止リストの初期値**: 紫や青のグラデーション・光・レンズフレア / 飾りの浮遊粒子 / 全部同時にフェードイン / すべてに「フェード+下から上へ」 / 全部中央揃え / 読んでいる最中に動く文字。**初回の書き出しで使われた既定の癖を名前で足していく**
- **感覚の注文を数値に直す**: 「目立たせて」=1.0→1.08→1.0 を6コマ・山を拍に / 「上質に」=入りは ease-out-quint・ばね0.8・文字は弾ませない / 「間延び」=静止を1拍短く / 「うるさい」=主役以外は150ms 遅れ・60%の距離 / 「AIっぽい」=使われた既定の癖を名前で禁止
- **確認の回し方**: 静止画を数コマ出して見る → コマ番号付きで1〜2点ずつ直す(7つ同時に直すと作り直しになる)。直したことは「描画の約束」に追記して二度と起こさない

## 7. 失敗の記録

### 2026-10-20 v5 ボツ(ユーザー評価:「みづらい・音がうざい・演出がうざい・画面も何もかもみづらい」)
- 原因: 演出を足すほど良くなると考え、効果音7種・揺れ・バースト・光・金色・粒子・ランキング表・進捗バー・2段の見出しを同時に入れた。`critic.py` は数値(テンポ・音量)しか見ておらず「見やすさ」を測れていなかった。
- 学び: ユーザーが自分で作って評価した「目利き」ショート(見出し固定・カード大・字幕だけ)が基準。足すのは1回に1つ、ユーザーが見てから。
- 対応: `rich_short.py --simple`(黒背景・見出し・カード・字幕のみ・効果音なし)を既定の出発点にする。
