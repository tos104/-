## 2. 転用の考え方

型は「ジャンル」ではなく「視聴者の感情の動き」で捉える。遊戯王の型をポケカ・ドラゴンボールに移すときは、次の 3 つを入れ替えるだけにする。

- **対象**: 青眼 → リザードン / 悟空
- **価値の軸**: 値段・希少性・見分け方・後悔
- **形式**: N選 / 鑑定結果は？ / 1年前と今

例: 「1 年前は 100 万以下 → 今 240 万」(価値の時間差) は、どの TCG の高騰カードにも同じ形で使える。

## 3. 枠の外のアイデア(未検証・試す価値順)

1. **鑑定結果の予想を視聴者にさせる**: 「PSA 何点だと思う？」で止めてコメントを集め、結果は次のショートで出す(続きを見る理由 = 登録の理由)。
2. **長尺 1 本 → ショート 5 本の分解を前提に撮る**: 撮影前に「5 つの一言」を決めてから撮る。切り抜きではなく、素材集めとして撮影する。
3. **値段の時間差シリーズ**: 過去動画の映像 + 現在の相場で「あの時買ったカードは今いくら？」。既存の素材を使い回せる。
4. **失敗・損の回**: PSA9 / ケース割れ / 買い時を間違えた系は、参考 2 チャンネルとも伸びている(タイヘイ「【悲報】購入タイミングを間違えました」22 万)。
5. **コメントへの返信ショート**: 実在するコメント(例:「ケースのスタンド名は？」「海外代行はどこ？」)に答える。質問をした本人が拡散してくれる。

## 4. 業界知見(2026-10 調査・二次情報を含む)

- **「視聴された割合(スワイプされなかった割合)」が最初の関門**。目安は 70〜80%。ただし YouTube 公式の基準値はなく、出典は第三者ブログ。自チャンネルの似た長さのショート同士で比べるのが確実。
- **2025-03-31 以降、ショートは再生が始まった瞬間に 1 再生**(最低視聴時間なし)。再生数だけでは「見られたか」がわからないので、上の割合を見る。
- **冒頭 3 秒で残るかが決まる**(複数の解説記事で一致。一次情報ではない)。
- **収益化ポリシー「inauthentic content(量産・テンプレ)」**: 2025-07 に名称変更、2026-07 に例示が明確化。AI ナレーション自体は即アウトではないが、「同じ構成・同じテンポ・キーワードだけ差し替え」は対象になりうる(二次情報)。→ 1 本ごとに企画の切り口を変える。
- 読み: 青眼 = ブルーアイズ、真紅眼 = レッドアイズ(narr_short.py の READINGS に登録済み)。

## 4.9 制作の流れ(5 層)

1. **監督**: `briefs/*.md` に一文・視聴者・素材・禁止事項・各カットの理由を書く
2. **参照**: 上のスタイルガイドを守る。新しい参考は実測してから表に足す
3. **タイムライン**: 台本 JSON(`scripts/`)。各行に `note` で理由を書く
4. **描画**: `rich_short.py`(同じ台本からは毎回同じ映像が出る)
5. **批評**: `critic.py` が FAIL を出したら直して再書き出し。全部 PASS するまで渡さない

## 5. 制作の分担

- 委託元の最新ショート 10 本(2026-10-19 時点)はユーザー制作。`tracker.py` の `USER_MADE` で [自作] 表示。
- 新しい動画は必ず **絵コンテ(storyboard.py)→ ユーザー確認 → 書き出し** の順。
