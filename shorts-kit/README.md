# shorts-kit(ショート制作スタジオ)

会話ではなく、ファイルに決定を残す。次の動画はブリーフと素材を差し替えるだけで、同じ品質の手順で作れる。

| 場所 | 役割 |
|---|---|
| `briefs/` | 監督: 一文・視聴者・素材・禁止事項・各カットの理由 |
| `PLAYBOOK.md` | 参照: スタイルガイド(実測値)、心理チェックリスト、実験ログ |
| `scripts/` | タイムライン: 台本 JSON(各行に理由 `note`) |
| `fonts/` `se.py` | 承認済みの素材(書体・効果音) |
| `rich_short.py` | 描画: 同じ台本からは毎回同じ映像(乱数も固定) |
| `critic.py` `reviews/` | 批評: 数値の検品と、欠陥上位3つの記録 |
| `copy/` | 投稿文セット(タイトル・説明文・タグ) |
| `research/` | 市場分析・motion-prompt の名前一覧 |

## 動きのルール(物の種類ごと)
| 種類 | 動き |
|---|---|
| 字幕・ランキング表(小さな要素) | 素早く入る。行き過ぎはほぼなし(`snap_in`) |
| 見出し・冒頭フック | 強く入り、読める長さだけ止まる(`pop_in` / マスクリビール) |
| 順位バッジ(イベント) | 叩きつけ+行き過ぎ+バースト+揺れ。ここだけ派手にする |
| 映像(カメラ) | ゆっくり寄る。強く寄るのは順位の発表だけ |

## 完成の判定(この順で、全部満たすまで渡さない)
1. 絵コンテをユーザーが確認
2. `critic.py` が全項目 PASS
3. コンタクトシートで欠陥上位3つを記録し、その箇所だけ直して再確認(`reviews/`)
4. 投稿文セットがある

16:9 や 1:1 の版は今は作らない(YouTube ショートのみのため)。必要になったら、切り抜きではなく配置を作り直す。
