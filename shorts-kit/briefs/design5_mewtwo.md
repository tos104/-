# Shorts デザイン5案(ミュウツー 2,000円→PSA9 の同じ場面で比較・2026-11-05)

画像: `design5_mewtwo.png`(作図 `design5_mewtwo.py`。素材は元動画のコマ、文字は台本と字幕の事実だけ)

| 案 | 中身 | 根拠 |
|---|---|---|
| 1 カード大写し+スタンプ | カードを画面の主役に、答え(倍率)は判子 | 自チャンネルの当たり(約2万再生)の型(research/own_hit_dbsd_advance.md)・H7 |
| 2 3段+レシート | 上=問い、中=元動画、下=金額の表 | 実験ログで伸びた型(究極竜 5,206・FW 3,669) |
| 3 吹き出し | 映像を大きく、本人の言葉を吹き出し | 映像を広く使える。字幕と同時に出すと同じことを2か所で言う |
| 4 サムネ特化(型C) | 1コマ目=サムネ。左カード+右の短い行 | 書き出し済み(variant_mewtwo_psa_C.mp4) |
| 5 値段の物差し | 2,000円/16万/200万を棒で(対数) | 金額の差を一目で。答えの棒が結果で色付く |

外部の目安(業者ブログ。公式の数値ではなく、出典ごとに食い違う): 文字は画面の高さ 20〜70% に、下20%と右15%は UI に隠れる / 1画面1つの要点・約1.5秒で読める量 / 白文字+黒フチ / 字幕入りは維持率が上がるとの主張(出典なし)。横長の映像を縦に置いたときの維持率の比較研究は見つからず → 自チャンネルで比べる。
