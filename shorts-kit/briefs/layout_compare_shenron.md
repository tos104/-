# 絵コンテ: 3つの型の見比べ(ラストシークレット神龍 3.5万→10万)

- 目的: ユーザーが共有した「切り抜きの定番レイアウト3型」(上下分割 / 吹き出し / サムネ特化)を、同じ場面で並べて選ぶ
- 場面: `psa48_cliplist.md` 案2(元動画 32:02〜34:32)。文字は元動画の字幕・声だけ(「サ終決定で暴落」「仕入れ35,000円 鑑定後100,000円」「流通がかなり少ない」「一生価値が上がり続ける」)。「一度暴落したカード、今いくら？」は切り抜きリストの冒頭の問い**案**
- 画像: `layout_compare_shenron.png`(作図 `layout_compare_shenron.py`)。灰色の枠は元動画のコマに置き換える所(この環境に元動画がないため)。水色の枠は Shorts の UI
- 関門: 2(絵コンテの承認)の前段。型が決まったら、元動画のコマで `storyboard.py` の絵コンテを作る

## 共有された型を PLAYBOOK と照らして変えた所
| 共有の内容 | 変えた所 | 理由 |
|---|---|---|
| 見出し例「※衝撃の結末」「一同騒然」 | 見出しは字幕の事実(金額・「サ終決定で暴落」) | 4.95-9 見出しは中身 / 4.45 AIっぽさ / 事実でないあおりは使わない |
| 配色 白+黄/赤+水色 | 白+黄 #FFE600+赤 #FF2A2A(4.8 の基準) | 3色以内は同じ。水色は Shorts UI の目印と紛れる |
| フォント 源ノ角ゴ Heavy 等 | Dela Gothic One / Rounded M+ 1c Black | 4.8 の基準。手元にある |
| 文字の3層(色+影+フチ) | そのまま | 4.8 と同じ |
| サムネ型「左に表情・右に文字」 | 左にカード・右の文字は x 640〜940 に収める | tt の映像の主役はカード(H7)。縦型では右端が Shorts のボタンに隠れる |

## 型ごとの見立て(推測)
- 型A 上下分割: tt が今使っている3段レイアウトに最も近い。実験ログで伸びた型の延長なので、まず比べる基準
- 型B 吹き出し: 映像を全面で使えるのでカードが大きい(H7)。声の要点を出すのに向く。字幕と吹き出しが同時に出ると「3つの枠で同じことを言う」(4.95-8)になるので1つに絞る
- 型C サムネ特化: 1コマ目=サムネとして強いが、2コマ目以降は別のレイアウトに切り替わる(型が2つ混ざる)
- 最後の「3.5万→10万」の A→B 表記は、タイトルでは弱い(4.7)。画面の中で使うのは別の話だが、比べる価値あり
