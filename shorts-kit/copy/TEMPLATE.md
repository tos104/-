# 投稿文セットの型(ユーザーの見本 2026-10-20 より)

```
【タイトル】
<フック(金額・数字)>、<問い or 結果>【<ジャンル>・<キーワード>】

【説明文】
<何のカードか 1〜2行。絵文字は1行に1つまで>
<見どころ。番号つきリスト①②③で「保存したくなる」知識>
<最後に知る人だけのポイント or 結果への引き>

※<相場の注記: 撮影時の相場であり、実際の購入額・売却額とは異なる>

全編は関連動画をチェック😎

【ティーティーチャンネル】
ポケカ・ドラゴンボール・遊戯王などのPSA鑑定結果や、高額カード・フィギュアのコレクションを紹介しています✌🏽

#<ジャンル> #<カード名> #<鑑定> #<特徴>(3〜5個)

【タグ】
<カード名(日本語)>,<略称>,<英語名>,<ジャンル>,<英語ジャンル>,<特徴>,<鑑定(表記ゆれ込み)>,ティーティーチャンネル,tt-channel-777
```

ルール
- 見出しは【説明文】【タグ】に統一(見本では【概要欄】【タグ欄用】も混在)
- 金額・枚数・カード名は動画内の声かテロップにあるものだけ
- 英語名は公式の英語版カード名を使う
- URL は書かない(ショートの概要欄のリンクは押せないため。2026-10-24 ユーザー指示)。全編への導線は「全編は関連動画をチェック😎」
- 投稿文は毎回 2 案出す: A=結果を見せる / B=結果を伏せる(タイトル・説明文とも答えを書かない)。切り抜きごとに交互に使い、48 時間後の再生数で比べる
- タイトルは最初の画面の文字と言葉を重ねない(同時に見えるので、2 枠で別の情報を出す)。画面=その場の問い、タイトル=画面に無い背景・正式名・希少性
- 関連動画は内容が一致する本編に直接つなぐ(ショート経由にしない)。設定先を投稿文ファイルの先頭に「関連動画に設定: <動画ID>」で書く
- タイトルの【】は必須ではない(競合で有無の差なし ×0.97)。チャンネル紹介文の末尾は「✌🏽」まで(2026-10-29 ユーザー確定版)
