# 投稿文セットの型(ユーザーの見本 2026-10-20 より)

```
【タイトル】
<フック(金額・数字)>、<問い or 結果>【<ジャンル>・<キーワード>】

【説明文】
<何のカードか 1〜2行。絵文字は1行に1つまで>
<見どころ。番号つきリスト①②③で「保存したくなる」知識>
<最後に知る人だけのポイント or 結果への引き>

※<相場の注記: 撮影時の相場であり、実際の購入額・売却額とは異なる>

全編は関連動画をチェック😎

【ティーティーチャンネル】
ポケカ・ドラゴンボール・遊戯王などのPSA鑑定結果や、高額カード・フィギュアのコレクションを紹介しています✌🏽

#<ジャンル> #<カード名> #<鑑定> #<特徴>(3〜5個)

【タグ】
<カード名(日本語)>,<略称>,<英語名>,<ジャンル>,<英語ジャンル>,<特徴>,<鑑定(表記ゆれ込み)>,ティーティーチャンネル,tt-channel-777
```

ルール
- 見出しは【説明文】【タグ】に統一(見本では【概要欄】【タグ欄用】も混在)
- 金額・枚数・カード名は動画内の声かテロップにあるものだけ
- 英語名は公式の英語版カード名を使う
- URL は書かない(ショートの概要欄のリンクは押せないため。2026-10-24 ユーザー指示)。全編への導線は「全編は関連動画をチェック😎」
- 投稿文は毎回 2 案出す: A=結果を見せる / B=結果を伏せる(タイトル・説明文とも答えを書かない)。切り抜きごとに交互に使い、48 時間後の再生数で比べる
- タイトルは最初の画面の文字と言葉を重ねない(同時に見えるので、2 枠で別の情報を出す)。画面=その場の問い、タイトル=画面に無い背景・正式名・希少性
- 関連動画は内容が一致する本編に直接つなぐ(ショート経由にしない)。設定先を投稿文ファイルの先頭に「関連動画に設定: <動画ID>」で書く
- タイトルの【】は必須ではない(競合で有無の差なし ×0.97)。チャンネル紹介文の末尾は「✌🏽」まで(2026-10-29 ユーザー確定版)


## FX(nori・@norifx2058)の投稿文(ユーザー修正から学習 2026-10-28・2026-11-01)

確定版の実例: `fx_usdjpy_box_v8.md`(確定版)、`fx_usdjpy_1022_v13.md`(最終版)

- タイトル: 「〜ても まだ売らない/すぐ買わない」のように、**待つ**ことを言い切る。手法を知らない人にも分かる言葉だけ(MAribbon・切り下げラインなどはタイトルに入れない)
- 説明文の 1 行目: 失敗の場面を問いにする(「〜した瞬間に売ったら、すぐ戻された経験はありませんか？」)
- 説明文の 2 行目: **誰の悩みか+答えの一言**(例「教科書通りにやってるのに勝てない人は待つことがポイントです。」)。導線はここに置かない
- 手順: 入り方には **MAribbon の条件**を必ず入れる(例「右肩に ribbon が抑え込むようにかかっている所に切り上げラインを引き」)。ラインだけ書くと手法の説明にならない
- 時間が進んだ所は「進んだチャートを引いて見ると」のように、進んだことを書く
- 用語は ( ) で言い換える。決済の三尊チャネルは「三尊の肩の角度を使ったチャネル」
- 詳しい解説への導線: 1022 では「メンバーシップ動画で詳しく解説してます。」(box では「関連動画」)。どちらにするかは毎回ユーザーに確認する
- 最後に【動画の色の帯(MAribbon)】の説明、免責(日付・通貨・足・教育目的・保証しない)、#FX #ドル円 #FX初心者
- 「コメントで教えてください」は 1022 で削除された。入れるかは毎回確認
- 書かない: 利益額・pips・勝率・「必ず」「勝てる」、動画で扱っていない損切り位置
