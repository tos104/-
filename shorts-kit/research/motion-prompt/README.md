# motion-prompt の名前一覧(抜粋)

出典: https://github.com/showheyohtaki/motion-prompt (Shohei Ohtaki, MIT License。`LICENSE` を参照)
`names_ja.json` は packs の motion / motion2 / camera / photo の日本語の一覧から、番号・名前・英語名・ひとこと・頼み方の例を抜き出したもの。

絵コンテと指示は、この番号で話す(例:「#2の順位発表に #024 インパクトシェイクを強めに」)。

## rich_short.py での対応

| 番号 | 名前 | 実装 |
|---|---|---|
| #001 | ポップイン | 字幕・見出し・ランキング表 |
| #002 | スタガー | 冒頭フック(0.4 秒ずつ) |
| #003 | バースト | 順位バッジの周りに放射線 |
| #005 | マスクリビール | 冒頭フックが枠の下からせり上がる |
| #007 | カウントアップ | 図解の数値 |
| #010 | オーバーシュート | ポップインの行き過ぎ |
| #022 | ライトスイープ | `shine` |
| #024 | インパクトシェイク | 順位バッジの瞬間に映像を揺らす |
| #028 | ズームイン | `zoom: push / punch` |
| #036 | ダッチアングル | 右肩上がりの傾き(バッジ 6°・フック 3°) |
| #040 | フリーズフレーム | `freeze` |
| #041 | ジャンプカット | 本人の声の区間つなぎ |
| #112 | 周辺減光 | 全体 |
| #118 | フィルムグレイン | 全体 |

未実装で次に試す候補: #047 Jカット(次の音を先に聞かせる)、#038 スピードランプ、#129 テキストスクランブル(金額の発表)、#043 ホイップパン(転換)。
