## 著者とチャンネル

- nori(@norifx2058)。カバーディーラー出身、2014 年に独立した専業トレーダー。MW チャネルは著者独自(p.30, p.148, p.309)
- 書籍の軸: 「Don't think. Follow the trend」(p.308)。予想しない・流れが出てから従う(p.20, p.282)
- 「勝ちを狙う」より「負けにくい・逃げやすい所で勝負」「リスクが小さいからトレードする」(p.22-23)
- 15 分足が基本。兼業は 1 時間足・4 時間足を推奨(p.45)

## トレードの 5 つのルーティン(p.24-25)

1. 推進波と修正波(p.27-31)。推進波の後は修正波を挟んで必ず「ペア」の推進波が出る(ペア理論)
2. MA(MAribbon)(p.33-)
3. 抵抗帯(三尊・逆三尊・アセンディング/ディセンディング・ダイヤモンドの 5 つ。p.102-103)
4. 切り上げ・下げライン(p.120-)
5. 決済用チャネル(N・MW・三尊。p.147-)

## MAribbon(p.45-47)

- 短期 MAribbon = 20SMA・40SMA の帯。上向き赤・下向き青
- 長期 MAribbon = 75EMA・200SMA の帯。上向き黄・下向き緑
- 15 分足の長期 MAribbon ≒ 1 時間足の短期 MAribbon(p.50-51, p.214)
- 推進波で帯が広がり(拡散)、修正波で縮む(収縮)(p.48-49, p.86)
- 注: 以前ユーザー共有の「手法ナレッジ」は短期帯を桃/水色としていた。書籍は赤/青

## MAribbon のトレードポイント(p.50-)

1. 長期 MAribbon の色が変わった後の **1 回目の押し・戻し**(2 回目以降は優位性が落ちる)(p.51)
2. 短期 MAribbon × 75EMA の交差(急上昇後・レンジ内の交差は除く)(p.53-59)
3. **短期 MAribbon が横に交差する形からのブレイク**(p.59-62)
   - 短期 MAribbon が横に交差 = レンジ。中では何もしない
   - レンジの目安: できれば 20SMA と 40SMA の交差が 3 回以上(p.60)
   - ローソク足の上下の抵抗で BOX を引く → 短期 MAribbon が BOX から出るのを待つ → ローソク足が短期 MAribbon に押し・戻しを付けるのを待ってエントリー
   - **→ 今回の動画(fx_usdjpy_box)はこの型**
4. 天井の短期 MAribbon 交差(p.63-64)
5. 大陽線 + 短期 MAribbon 交差 + 大陰線(p.65-68)
6. 200SMA を短期 MAribbon が通過する時(p.69-72)

## トレードしてはいけない所(p.73-93)

レンジの中 / 短期 MAribbon の 3 つ目の膨らみ(突っ込み買い・売り)/ 短期 MAribbon から離れた所 / 長期 MAribbon が広がりすぎ / 急騰・急落後 / 逆張り

## 切り上げ・下げライン(p.120-146)

- 切り下げライン = 上昇中の押しに引く(買い)。切り上げライン = 下降中の戻りに引く(売り)
- 3 つのルール: ① 75EMA に対角に引く ② 裏側から角度を取りフラッグにする ③ 4 点目ブレイクを意識(①+② か ③ ならなお良い)(p.122)
- 接地点が多く、時間足に合ったラインを引く。苦手ならハル移動平均線(HMA)を代用(p.137-146)

## 決済(p.147-204)

- 決済に使うのは主に**値幅チャネル**(N・MW・三尊)。センターラインを必ず表示(p.147, p.150)
- トレンドチャネルは「その他の決済方法」。「MAribbon のそばから買いエントリーした場合、トレンドチャネル上限に価格がタッチしたところで」決済(p.196。書籍の画面録画 IMG_6048 で確認済み)。効いているかはブレイク前後の動きで判断(p.197-201)
- 水平線(抵抗帯から抵抗帯)での決済でもよい(p.202-204)

## 損切り(p.111-113)

pips で置かず、根拠のある所(抵抗帯の下)に置く。ただし抵抗帯を割ってもダウ転換とは限らないので、余裕を持つなら三尊の肩でのエントリーは三尊のネックラインの下、逆三尊のネックラインでのエントリーは逆三尊の肩の下。損切り幅を広げたら利確も同じだけ広げ、最低でも利確:損切り=1:1(p.112。画面録画で確認済み)

## ショートの題材になりそうな著者独自の考え

- 8020: キリ番(.00/.50)より .20/.80 の方が止まりやすい(p.271-274)
- MW チャネル(著者の独自手法)(p.30, p.158-173)
- 「三尊=下」と決めつけない。MA の位置で軌道が変わる(p.113-116)
- 大陽線 + 短期 MAribbon 交差 + 大陰線のペア(p.65)
- 勝ち負けの差は手法より「週に 1 回の小さなミスや迷いからの自滅」(p.281)
- 練習法: 毎朝上下の軌道を描く → 週末に振り返り(p.292-298)
